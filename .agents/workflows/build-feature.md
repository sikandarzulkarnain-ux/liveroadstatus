# BUILD FEATURE


When implementing a feature:


1. Understand the request.
2. Inspect existing architecture.
3. Identify reusable components.
4. Identify affected files.
5. Identify database/API implications.
6. Create a concise implementation plan.
7. Implement the smallest maintainable solution.
8. Do not rewrite unrelated code.
9. Keep data logic separate from UI.
10. Validate external data.


After implementation:


11. Run lint.
12. Run tests.
13. Run production build.
14. Start the application.
15. Open the website in the browser.
16. Test the feature.
17. Test desktop.
18. Test mobile.
19. Check console errors.
20. Check network/API errors.
21. Check accessibility.
22. Check SEO.
23. Fix problems.
24. Review git diff.


Final report must include:


- files changed
- features implemented
- tests performed
- browser tests performed
- problems found
- problems fixed
- remaining issues


Never say "done" without verification.
